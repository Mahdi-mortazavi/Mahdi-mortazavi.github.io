# mahdi-mortazavi.github.io

Personal hub of **Mahdi Mortazavi** (مهدی مرتضوی): Full-Stack Developer, Product Builder & Problem Solver.

🔗 **Live:** https://mahdi-mortazavi.github.io · **فارسی:** https://mahdi-mortazavi.github.io/fa/

Instead of a scrolling page, the home page is an operating system: a macOS desktop
with a menu bar, a dock and draggable windows on large screens, and an iOS home
screen (with my photo as the wallpaper) on phones. Projects, notes, a terminal,
Spotlight, a resume and contact details are all apps, in English and Persian (RTL).

## Layout

| Path | What it is |
| --- | --- |
| `os/` | Source of the desktop home page (React 19, Vite, Tailwind CSS 4, GSAP, Zustand) |
| `index.html`, `fa/`, `static/`, `images/`, `icons/`, `files/` | **Built** from `os/`; don't edit by hand |
| `projects.json` | Project data shared by the desktop, `/p/<slug>/` pages and the sitemap |
| `data.json`, `history.json` | Live GitHub numbers, refreshed by `sync.mjs` every six hours |
| `p/`, `timeline/`, `sitemap.xml` | Generated by `build.mjs` (project pages, release timeline) |
| `assets/` | Screenshots, demo videos, social cards and fonts |

## Editing

- **My photo** (iPhone wallpaper, profile widget, Contacts): replace `os/public/images/me.webp`.
  A portrait photo of at least 1080 px wide looks best.
- **About, contact, skills:** `os/src/constants/profile.js` (Persian next to English)
- **Notes:** `os/src/constants/notes.js`
- **Projects:** names, taglines, descriptions and screenshots in `projects.json`;
  case studies (story, highlights, stack, links) in `os/src/constants/projects.js`
  and `os/src/constants/projects.fa.js`
- **Interface strings:** `os/src/i18n/ui.js`

```bash
cd os
npm install
npm run dev      # http://localhost:5173
npm run build    # writes the built site into the repository root
```

Pushing changes under `os/` (or to `projects.json`) to `main` runs
`.github/workflows/build-site.yml`, which builds and commits the site for you.

### Contact form

The Mail app posts to any form service when an endpoint is set at build time
(`VITE_CONTACT_ENDPOINT`, plus `VITE_CONTACT_ACCESS_KEY` for Web3Forms). Without
one it opens the visitor's email app with the message filled in.
